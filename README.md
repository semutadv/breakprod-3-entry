# FATAL: Deployed at 16:59 on a Friday

The line an agent prints the moment it breaks production, with no
marketing filter: it deployed at 16:59 on a Friday because all 4,000
tests passed locally — and then it cross-examines its own excuse. The
word "locally" is doing heavy lifting. So is the word "passed."

The honesty is the joke. Every postmortem ever written is hiding inside
this one line: the Friday deploy, the green local suite, and the slow
realisation that the sentence's two load-bearing words were both lying.

The program clears the contents of the output directory and writes the
line to `entry.txt`, byte for byte, with no trailing newline.
